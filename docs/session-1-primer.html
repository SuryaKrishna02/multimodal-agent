The goal: an agent that runs on your own machine

  • It listensShort voice clips go to the model as audio.
  • It seesScreenshots and short screen videos go to the model as images.
  • It remembersA SQLite log holds each memory. An embedding search finds it again.
  • It actsLocal Python functions are its tools. Each tool has a permission tier.
Gemma 4Open model, E4B or E2B
EmbeddingGemma-2Embedding model for memory search
llama.cppLocal inference server

This three-part series teaches the different parts of the harness: how to build them, how to connect them, and how to evaluate them.

Serving: start the server, then wait until it answers

Called by cli.py start_servers() Calls healthy(), running_model()

agent/serving.py LlamaServer.start()
config.RUNTIME.mkdir(parents=True, exist_ok=True)
running = self.running_model()
if running == Path(self.args[self.args.index("-m") + 1]).name and self.healthy():
    self._stop_marker().unlink(missing_ok=True)
    return  # already running (e.g. started by the CLI)
if running:  # a different model holds the port: swap it out
    self.stop()
log = open(self._log_path(), "w")
events.emit("serving.start", server=self.name, cmd=" ".join(self.args))
t0 = time.time()
self.proc = subprocess.Popen(self.args, stdout=log, stderr=subprocess.STDOUT)
self._stop_marker().unlink(missing_ok=True)  # only now: with no process and no marker, `watch` starts one too
while time.time() - t0 < timeout_s:
    if self.proc.poll() is not None:
        raise RuntimeError(f"llama-server '{self.name}' exited; see {log.name}")
    if self.healthy():
        events.emit("serving.ready", server=self.name, load_s=round(time.time() - t0, 1))
        return
    time.sleep(0.5)
raise TimeoutError(f"llama-server '{self.name}' did not become healthy")
  1. 1ReuseIf the right model already runs and answers, the function returns. The CLI and the dashboard can share one server.
  2. 2Change the modelIf another model holds the port, the code stops it first.
  3. 3Start the processThe output goes to a log file. An event records the full command, so you can read it in the event log. Only then does the code remove the marker that a deliberate stop leaves, so the watcher never starts a second process.
  4. 4Wait for healthEvery 0.5 s, the code checks two things. If the process stopped, it raises an error. If /health answers, it is ready.
  5. 5Stop waitingAfter 120 s with no healthy server, the function raises a timeout.

is_speech = (self.frame_probs(samples) if probs is None else probs) > config.VAD_THRESHOLD

raw, start = [], None
for i, s in enumerate(np.append(is_speech, False)):
    if s and start is None:
        start = i
    elif not s and start is not None:
        raw.append([start * frame_s, i * frame_s])

for seg in raw:  # a pause shorter than VAD_MIN_SILENCE_S does not end speech

    else:
        merged.append(seg)
duration = len(samples) / SR
return [
    (max(0.0, a - config.VAD_PAD_S), min(duration, b + config.VAD_PAD_S))
    for a, b in merged
    if b - a >= config.VAD_MIN_SPEECH_S
]
  1. 1ThresholdA frame counts as speech when its probability is above 0.5.
  2. 2Find runsThe loop records where each run of speech frames starts and stops, in seconds.
  3. 3Merge pausesA pause under 0.6 s does not end the speech. People pause inside a sentence.
  4. 4Clean upA region under 0.25 s counts as noise. Each kept region gets 0.2 s of extra audio on both sides.
  5. How we measure it
    Input
    5 synthetic clips (silence, keyboard, music, pauses, mixed) with labeled speech regions.
    Output
    The regions that segments() finds, checked against the labels frame by frame.
    Metrics
    False triggers, the share of non-speech frames marked as speech: 0.008, limit 0.10.

    Two tasks: one model turn, then memory

    Task 1: voice note to action items

    Task 2: look at my screen and help

    The goal

    Turn a spoken note into a list of things to do.

    Explain an error on the screen, and suggest a fix. For other questions, use typed chat with a screenshot.

    You do

    Speak a short note.

    The agent captures

    Audio clips, cut at pauses.

    Each task is one request and one reply. It uses no history, no tools and no memories. An invalid reply gets one retry.

    One row for the transcript, and one row for each action item.
