Serving

Two local servers do the model work: a language model that reads text, images and audio, and an embedding model that powers memory search. Nothing leaves this machine.

Servers

E2B is the smaller model: it uses less memory and replies faster. E4B is larger. Switch with the Model menu at the top. The memory number can drop while the model is idle, because the operating system can page out the model file. That is normal.
