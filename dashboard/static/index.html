    Always on

    The daemon is its own process that runs jobs while you do other things. It writes every step down, so a crash loses nothing.

    How a job runs

    1. Asked forBy the schedule, a trigger, or you
    2. QueueOne job runs at a time
    3. StepsIntent, execution, result: each is a row on disk
    4. FeedWhat it did, and the reason

    After a kill, the next start skips every step that has a result row. You can also start the daemon with python cli.py daemon start.

    Daemon

    The daemon transcribes what it hears with Whisper and stores it as raw memories. The Mic switch at the top still pauses it.

    What the agent did on its own

    Each finished job, newest first, with the reason it ran.

    Schedule

    Evolve

    The daily brief learns from your feedback. The model can change only the editable blocks of its prompt, and code checks every change.

    How feedback becomes a new version

    1. FeedbackYour words on a brief
    2. PatchThe model proposes a change
    3. ValidateCode: editable blocks only
    4. GateCode: no invented names or numbers on recent days
    5. New versionOld versions stay, so you can roll back

    Tasks

    The jobs this agent is built to do. Everything on the other tabs comes together here.

    Task 1: voice note to action items

    Speak, stop, and get a transcript with a list of what to do. Both are saved to memory.

    Task 2: look at my screen and help

    The agent says what it sees and suggests a fix if something is wrong.

    Task 3: ambient listener with recall

    Turn on always-on listening in the Always on tab, or replay the recorded morning conversation as if it started at 09:00. Then ask about it.

    Task 4: self-improving daily brief

    Writes today's brief from summaries, facts, action items and screen episodes, with the active prompt version. Tell it what to change, then reflect.
